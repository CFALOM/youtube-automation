# Viral Facts Shorts V2

Retention-focused no-paid-API prototype.

It improves V1 with:
- a curiosity-gap hook and escalating bridges
- multiple relevant Wikimedia Commons visuals when available
- different visual every scene
- slow zoom/pan motion instead of static cards
- word-group animated captions timed to narration
- scene-change sound effects
- 9:16 1080x1920 rendering
- Piper local/offline TTS
- FFmpeg rendering

Important: no automation can guarantee an "unskippable" video or viral views. YouTube says Shorts ranking considers whether viewers choose to watch, average view duration, average percentage viewed, and satisfaction signals. The system should therefore be tested against Analytics and improved from real retention data.
