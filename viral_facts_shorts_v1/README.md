# Viral Facts Shorts V1

Phone-friendly GitHub Actions starter for generating a vertical facts Short without paid AI APIs.

## Run
1. Create a public GitHub repository.
2. Upload this folder.
3. On your phone, open **Actions** → **Create Viral Facts Short** → **Run workflow**.
4. Download the `short-video` artifact after the workflow finishes.
5. Upload the MP4 to YouTube Shorts.

This version uses a curated fact database and templates rather than a cloud LLM, so there are no OpenAI/Gemini/ElevenLabs API keys.

Note: GitHub Actions and YouTube still have their own platform limits. This project does not bypass them.
